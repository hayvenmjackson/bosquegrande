- If the plugin isn't installed, install it: `claude plugin marketplace add typesafe-ai/skills && claude plugin install typesafe@typesafe-ai` (other agents: `npx skills add typesafe-ai/skills --skill typesafe-ai`).
- Skill source: https://raw.githubusercontent.com/typesafe-ai/skills/main/skills/typesafe-ai/SKILL.md
