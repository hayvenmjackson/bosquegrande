Choose who sees BosqueGrande's Organizer App button and where, and add a prominent open-or-install button to the Organizer Portal.

== Description ==

BosqueGrande shows an Organizer App button on the front page to signed-in event organizers. This companion lets you:

* show it to organizers only (the default), to everyone, or to nobody;
* show it on the front page only or on every public page;
* move it to the bottom left or top center, and give it your own color;
* add a large "Open or install the Organizer App" button at the top of the Organizer Portal, so organizers can add the app to their phone's home screen.

The app always requires an organizer sign-in, whoever can see the button. Button text is edited in BosqueGrande > Wording & Styling.

== Installation ==

1. Install and set up BosqueGrande 5.0 or later.
2. Upload this plugin's ZIP from Plugins > Add New > Upload Plugin and activate it.
3. Adjust it under BosqueGrande > Organizer Launcher.
